# Project Overview

The **Google Play Store Analytics Dashboard** is an end-to-end data analytics project developed during the **Google Play Store Data Analytics Internship**.

The project demonstrates the complete analytics workflow—from data cleaning and preprocessing to interactive dashboard development and business insight generation. Using Python, Streamlit, Plotly, and Power BI, the application enables users to explore application performance through dynamic visualizations and filters.

This project showcases practical skills in **Data Analytics, Business Intelligence, Exploratory Data Analysis (EDA), Data Visualization, Dashboard Development, and Reporting.**

---

# Objectives

- Clean and preprocess real-world Google Play Store data.
- Perform exploratory data analysis (EDA).
- Build interactive dashboards for business users.
- Visualize trends, distributions, and relationships.
- Generate actionable insights from application data.
- Support data-driven decision making through analytics.

# Installation

### Clone the repository

```bash
git clone https://github.com/your-username/Google_Play_Analytics_Internship_Project.git
```

### Navigate to the project folder

```bash
cd Google_Play_Analytics_Internship_Project
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the Streamlit application

```bash
streamlit run app.py
```

The application will automatically open in your browser.
